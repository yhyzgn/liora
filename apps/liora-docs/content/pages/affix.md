# Affix

将内容固定在特定可视区域中，适合长表单的提交按钮、工具条或需要持续可见的操作入口。Affix 通过 GPUI 布局测量与 Liora PassivePortal 完成固钉，不依赖浏览器定位。

## 顶部固钉

当滚动容器中的元素越过顶部阈值后，Affix 会把内容固定到窗口顶部指定偏移处，并在原位置保留占位尺寸避免布局跳动。

固钉与还原会请求完成可见状态变化所需的下一帧；关闭装饰动画时仍然生效，状态稳定后不持续请求帧。Gallery 与本页直接执行下面展示的顶部／底部构造函数。

固钉后会跟随原位置的横向移动和容器宽度变化：自动宽度内容在窗口缩窄、放宽后都会重新布局，内容显式设置的宽度约束仍然保留。实际内容高度（包括外边距）会修正占位与底部偏移。普通纵向滚动不会额外触发几何修正帧，`on_change` 仅报告进入／退出固钉状态。

复现方式：初始未固钉时，按钮应紧接“向下滚动查看固钉效果”的占位区域，与内容左边缘对齐；向下滚动此示例的内部容器，越过阈值后按钮固定在窗口顶部 80px 处，原位置保留占位。再滚回顶部，按钮应回到原来的内容位置，不出现额外偏移。

## 滚动容器

Affix 通常放在一个有明确高度的原生滚动容器内。将 `Entity<Affix>` 保留在父视图中，传给下面的完整容器函数；本页三种预览直接执行该函数并插入真实 Affix，不需要补写注释占位。外层 `relative`／`overflow_hidden` 约束容器，内层 `overflow_y_scroll` 提供滚动；固钉偏移仍相对窗口边缘，而不是容器边缘。

示例滚轮事件保留在内层容器（包括边界）；将指针移到示例外即可滚动文档。
