# Calendar

`Calendar` 是独立月视图日历，适合日程、发布计划、活动标记和日期范围展示。

日历展示固定月份，日期选择由宿主回调处理，不会自动切换月份或更新 `.selected(...)`。需要保留选择时，由宿主保存日期并在重绘时传回。

日历身份在重绘之间保留；直接在不同构造位置创建的日历相互独立。在同一循环或工厂位置创建多个实例时，用 `.id(...)` 为每个实例分配稳定且不同的身份。Gallery 和 Docs 执行下方相同示例，事件日历与范围日历各有独立身份。

## 键盘与焦点

`Calendar` 是只有一个 Tab 停靠点的复合控件，而不是每个日期各占一个停靠点。活动日期（键盘导航位置）在重绘之间保留，与宿主通过 `.selected(...)` 传入的选中日期分开；初始活动日期优先使用网格中可见的选中日期，否则使用当月第一个未禁用日期。

| 按键 | 行为 |
| --- | --- |
| `Tab` / `Shift+Tab` | 进入日历的单一停靠点，或按宿主焦点顺序向前／向后离开日历；不逐日遍历。 |
| `←` / `→` | 将活动日期前移／后移 1 天，仅在当前网格的可见日期之间导航。 |
| `↑` / `↓` | 将活动日期前移／后移 7 天，仅在当前网格的可见日期之间导航。 |
| `Home` / `End` | 移到活动日期所在周的第一个／最后一个可见日期。 |
| `Enter` / `Space` | 激活当前未禁用的活动日期，与指针选择走同一个宿主回调，每次激活只回调一次。 |

导航只移动活动日期，不选择日期、不触发选择回调，也不切换展示月份。可见的相邻月份日期可以参与导航；隐藏的相邻月份日期只是惰性空白，导航会跳过它们。可见的禁用日期仍可成为活动日期，但不能通过键盘或指针选择。保留选择仍需宿主保存回调日期并更新 `.selected(...)`。

键盘焦点以活动日期上的可见焦点轮廓呈现，不以选中样式代替。多个兄弟日历需要稳定且不同的 `.id(...)`，以隔离保留的活动日期与焦点身份，尤其是在同一循环或工厂位置构造时。

## 可访问性元数据

日历向 GPUI 提供网格、行和日期单元格（grid / row / cell）结构，日期单元格使用本地化的完整日期名称，并提供选中与禁用状态。选中状态来自宿主的 `.selected(...)`，不随键盘导航自动改变；隐藏的相邻月份空白不作为可交互日期暴露。

这些是组件提供的 GPUI 元数据与键盘行为契约，不代表已经通过各平台原生辅助技术或屏幕阅读器认证；平台实际的角色、名称、状态与朗读行为仍需原生观察验证。
