# 005 Agent Desktop SDK Capabilities

- 状态: 已完成
- 负责人: omp
- 当前任务: `.context/tasks/005_agent_desktop_sdk_20261112.md`

## 目标

按用户确认的 SDK 范围补齐原生 Agent 工作台可复用能力；每项实现、行为验证、独立审查和问题修复后才标记已完成。

## 非目标

不创建 Agent 产品，不实现 provider/CLI/app-server 连接、工具权限执行、会话数据库、MCP/PTY 子进程管理、OAuth/单实例/系统通知业务。不引入 WebView、DOM 或社区 GPUI fork。不自动提交、推送、发布。

## 约束和依赖关系

- 沿用官方 Zed GPUI 固定 SHA 与现有原生主题/事件机制。
- 共享导出、依赖、Gallery/Docs 导航由集成者修改，组件实现不耦合演示业务。
- 复用已有 pulldown-cmark、Input、CodeBlock、VirtualizedList、GPUI ListState/action/keymap；新增终端依赖必须先核对许可与 API。
- 布局先完成 Splitter，再完成 Dock；文档模型先完成，再接动态内容和会话视图。
- 保留现有调用契约；必须迁移的调用、snippets、测试随实现一起更新。

## 有序阶段与退出标准

1. 清单和上下文：逐项可观察验收、归属和证据落盘，通过 CTX 验证。
2. 内容与输入：动态 Markdown、会话滚动、Composer。连续更新、选择/滚动稳定、结构化引用/附件及输入提交有行为证明。
3. 审阅与执行视图：diff、终端。前者真实 hunk/行映射及接受拒绝事件，后者真实终端协议解析/显示/输入/尺寸事件；均不擅自执行或修改文件。
4. 工作台：Splitter、Dock、命令面板、编辑器。鼠标和键盘交互真实接通，布局恢复和编辑行为有证明。
5. 集成：Gallery/Docs、snippets、README/CHANGELOG 与集成验证；明确跨平台真实运行限制。

## 计划级风险与回滚

- 大范围公开接口和新依赖风险：按独立模块分批实现、审查、验证，不以空 API 或占位演示冒充完成。
- 文字选择/虚拟化/IME 和跨平台终端行为必须区分静态测试、原生运行和实机验证。
- 独立 Linux/Xwayland 会话已验证九项演示绘制和 Markdown 真实剪贴板/对齐选择；Composer 系统粘贴、实际 IME 候选窗、Windows/macOS 与硬件覆盖仍未验证，不据此宣称跨平台实机成功。
- 回滚以单工作项相关源码/依赖/文档为单位；不覆盖用户改动，不执行全仓重置。
